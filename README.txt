しずてつ 路線カード（Safari・Chrome だけで動く完全版）
=====================================================

■ ファイルの役割
  index.html          アプリ本体（これ1つだけでも動きます）
  manifest.json       ホーム画面に追加する時の設定（URLで公開した時に使われます）
  sw.js               オフラインで使うための設定（URLで公開した時だけ動きます）
  icon-192.png        アイコン（Android用）
  icon-512.png        アイコン（大）
  apple-touch-icon.png アイコン（iPhone用）

■ 一番かんたんな使い方
  index.html をブラウザで開く。（パソコン・Android はそのまま開けます）

■ iPhone で使う（おすすめ）
  1. 6つのファイルを、同じフォルダのまま、ネット上に置く（下の「公開のしかた」）。
  2. iPhone の Safari でそのURLを開く。
  3. 共有ボタン →「ホーム画面に追加」。以後はアプリのアイコンから開けます。
  ※ LINE やメールのプレビュー、「ファイル」アプリのプレビューでは動きません。必ず Safari で開いてください。

■ 公開のしかた（GitHub Pages・無料）
  1. github.com でアカウントを作り、新しいリポジトリ（Public）を作る。
  2. 6つのファイルをすべてアップロードして Commit する。
  3. Settings → Pages で Branch を main にして保存。
  4. 数分後、https://（アカウント名）.github.io/（リポジトリ名）/ で開けます。
  ※ URLを知っている人は誰でも見られます。会社の資料をもとにしているので、公開してよいか先に確認してください。

■ 路線データの足し方・直し方
  アプリの「路線データ」タブで直せます。書き方は次のとおりです。
    路線名 番号（区間）      ← 1行目（番号を書くと「系統」の問題に使われます）
    バス停名                 ← 2行目から、運行順に1行ずつ
    ※メモ                    ← 「※」で始まる行はメモとして表示
    ＠小鹿営業所 唐瀬営業所  ← 「＠」で始まる行は営業所の区分（複数ならスペース区切り）
  路線と路線のあいだは空行で区切ります。「保存」でこの端末に記録されます。
  全員に同じデータを配るには、index.html の中の SAMPLE の部分を書き換えます。

■ 保存されるもの（この端末のブラウザ内だけ）
  成績（回答数・正解率・連続日数）、苦手なバス停、前回の選択（営業所・路線・モード）、文字の大きさ、編集した路線データ。
  他の端末とは共有されません。

■ 更新するとき
  index.html を差し替えたら、sw.js の VERSION（'cards-v1'）を変えてください。
